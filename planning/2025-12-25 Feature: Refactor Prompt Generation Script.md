# Prompt Generation Script Refactor Plan

## 1. Restructure Configuration (`config/topics.yaml`)

- **Objective**: Update the YAML structure to support multiple output formats per topic and include new fields for priming text and content organization.

- **New Structure**:
  ```yaml
  topics:
    <topic_name>:
      priming_text: "..."
      supported_outputs: ["notion", "anki"]
      outputs:
        notion:
          ...
        anki:
          ...
  ```

## 2. Update Pydantic Models (`src/models.py`)

- **Objective**: Modify the Pydantic models to validate the new configuration structure.

- **New Models**:
  - `NotionOutputConfig`
  - `AnkiOutputConfig`
  - `OutputsConfig`
  - `TopicConfig` (updated)

- **Validations**:
  - Type safety
  - Required fields
  - Custom validator to ensure `supported_outputs` match `outputs`

## 3. Refactor Prompt Generator (`src/prompt_generator.py`)

- **Objective**: Update the `PromptGenerator` to use the new configuration.

- **Changes**:
  - Load the new configuration structure.
  - Dynamically generate `output_format_spec` based on the selected topic and output format.
  - Use the `priming_text` from the configuration.
  - Update templates to use a `{priming_text}` placeholder.

## 4. Implement Interactive CLI (`scripts/generate_prompt.py`)

- **Objective**: Replace the `click`-based CLI with an interactive one using `questionary`.

- **Workflow**:
  1. Prompt user to select a topic.
  2. Prompt user to select a supported output format.
  3. Get the video URL from the user.
  4. Call the refactored `PromptGenerator`.

## 5. Update Templates

- **Objective**: Modify the prompt templates to use the `{priming_text}` placeholder.

- **Files to Change**:
  - `templates/base_prompt.txt`
  - `templates/cooking.txt`
  - `templates/general.txt`

## 6. Testing

- **Objective**: Add unit tests for the new functionality.

- **New Tests**:
